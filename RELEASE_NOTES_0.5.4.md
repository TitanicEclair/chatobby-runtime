# Chatobby 0.5.4

- **Workspace permissions:** choose Read-only, Workspace or Full access, with saved workspace choices and one-time approval requests. These controls operate within Chatobby; OS sandboxing remains unavailable.
- **Context and memory:** report all open tabs accurately, keep useful task memory through tool calls, show clearer session summaries and refresh Memory across tabs.
- **Page and tool fixes:** open subagent conversations reliably, load Vault Events history and report stopped commands correctly.
- Updated model data, dependencies and bundled attribution.

Update the plugin, then use Chatobby's runtime update action. Chats, Projects,
memory and model connections are retained. macOS and Linux remain experimental;
macOS packages are not notarized.
